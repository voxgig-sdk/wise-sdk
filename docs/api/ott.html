API

Ott

A one-time token: verify its SMS, voice or WhatsApp challenge, or get its status.

Operations

Every route this entity exposes. Each route links to its own reference on this page.

Method Route SDK operation Returns

POST /one-time-token/voice/verify create One time token status
POST /one-time-token/whatsapp/verify create One time token status
GET /one-time-token/status load One time token status
