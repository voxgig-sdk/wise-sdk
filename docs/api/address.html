Address

A profile's address: create or update, list, or get one.

Operations

Every route this entity exposes. Each route links to its own reference on this page.

Method Route SDK operation Returns
POST /addresses create OK - Address successfully created or updated
GET /addresses list OK - Successfully retrieved addresses
GET /addresses/{addressId} load OK - Successfully retrieved the address
