API

Jose

JOSE keys, and a playground for testing JWS and JWE signing and encryption.

Operations

Every route this entity exposes. Each route links to its own reference on this page.

Method Route SDK operation Returns
POST /auth/jose/playground/jwsjwe create Signed and encrypted response
POST /auth/jose/playground/jwe create Encrypted response
POST /auth/jose/playground/jwe-direct-encryption create Encrypted response using direct encryption
POST /auth/jose/playground/jws create Signed response
POST /auth/jose/request/public-keys create Public key created successfully
GET /auth/jose/response/public-keys load Public key object
GET /auth/jose/playground/jwe load Encrypted response
GET /auth/jose/playground/jwsjwe load Signed and encrypted response
