Comparison

A comparison of what providers charge for a transfer.

Every route this entity exposes. Each route links to its own reference on this page.

GET /comparisons

Operation ID: comparisonGet.

Authentication: bearer token (UserToken) or bearer token (PersonalToken) or bearer token (ClientCredentialsToken).
