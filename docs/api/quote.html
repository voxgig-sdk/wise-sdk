Quote

A quote for a transfer: its exchange rate and fees.

Every route this entity exposes. Each route links to its own reference on this page.

create

POST /profiles/{profileId}/quotes

Operation ID: quoteCreate.

Authentication: bearer token (UserToken).

Parameters

Parameter In Type Required Description
profileId path integer (int64) Yes Personal or business profile ID of the sender.
X-External-Correlation-Id header string (uuid) No Optional UUID for correlating requests across systems. If provided, Wise echoes it back in the response. Maximum 36 characters. Learn more.

Request body

application/json

Property Type Required Description
creationContext object No Used to pass additional metadata about the intended transfer.
creationContext.flow string No Optional. Used to pass flow type for the creation flow on the quote. It should always be MASS_PAY for batch transfers funded via payin sessions.
payOut string,null No Optional. Preferred payout method. Default value is BANK_TRANSFER. Examples of other accepted values include BALANCE, SWIFT, SWIFT_OUR, ALIPAY, and INTERAC.
paymentMetadata object No Optional. Used to pass additional metadata about the intended transfer.
paymentMetadata.transferNature string No Optional. Used to pass transfer nature for calculating proper tax amounts (IOF) for transfers to and from BRL. Accepted values are shown dynamically in transfer requirements.
preferredPayIn string,null No Optional. Preferred payin method. Use BANK_TRANSFER to return this method at the top of the response's results.
pricingConfiguration object No Required when configured for your client ID. Includes a pricingConfiguration to be used for pricing calculations with the quote.
pricingConfiguration.fee object No
pricingConfiguration.fee.fixed number No The selected fixed fee that should be used in the pricingConfiguration. Always considered in source currency.
pricingConfiguration.fee.type string No Identifies the type of fee to be configured. Options include only OVERRIDE.
pricingConfiguration.fee.variable number No The selected variable percentage, in decimal format, that should be used in the pricingConfiguration.
sourceAmount number,null No Amount in source currency. Either sourceAmount or targetAmount is required, never both.
sourceCurrency string Yes Source (sending) currency code.
targetAccount integer (int64) No Optional. This is the ID of transfer recipient, found in the create recipient response. If provided, can be used as an alternative to updating the quote.
targetAmount number,null No Amount in target currency.
targetCurrency string Yes Target (receiving) currency code.
