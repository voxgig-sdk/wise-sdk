Operation ID: userCreate.

Authentication: bearer token (ClientCredentialsToken).

Parameters

Request body

application/json

Property Type Required Description
email string (email) Yes New user's email address.
language string No User default language for UI and email communication. Allowed values: EN, US, PT, ES, FR, DE, IT, JA, RU, PL, HU, TR, RO, NL, HK. Default value: EN.
registrationCode string Yes Randomly generated registration code that is unique to this user and request. At least 32 characters long. You need to store registration code to obtain access token on behalf of this newly created user in next step. Please apply the same security standards to handling registration code as if it was a password.
