API

CardOrder

A card order: create one, list or get them, update its status, and check requirements, programs and addresses.

Operations

Every route this entity exposes. Each route links to its own reference on this page.

Method Route SDK operation Returns
POST /spend/profiles/{profileId}/card-orders create OK - Card order created successfully
POST /spend/address/validate create OK - Validation result returned. An empty errors collection means the address is valid
GET /spend/profiles/{profileId}/card-orders/{cardOrderId}/requirements list OK - Successfully retrieved card order requirements
GET /spend/profiles/{profileId}/card-orders list OK - Successfully retrieved card orders
GET /spend/profiles/{profileId}/card-orders/availability list OK - Successfully retrieved available card programs
GET /spend/profiles/{profileId}/card-orders/{cardOrderId} load OK - Successfully retrieved card order
PUT /spend/profiles/{profileId}/card-orders/{cardOrderId}/status update Accepted - Card order status update has been accepted
