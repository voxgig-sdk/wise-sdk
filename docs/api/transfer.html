API

Transfer

A transfer: create, list, get or cancel one, and its receipts and payout information.

Operations

Every route this entity exposes. Each route links to its own reference on this page.

Method Route SDK operation Returns
POST /transfers create Transfer successfully created
GET /transfers list Returns an array of transfer objects, with or without an originator block depending on the type of each transfer
GET /transfers/{transferId} load Returns the transfer object, with or without an originator block depending on the type of transfer
GET /transfers/{transferId}/documents/noc load Non objection certificate in PDF format
GET /transfers/{transferId}/invoices/bankingpartner load Returns payout information for the transfer
GET /transfers/{transferId}/receipt.pdf load Transfer confirmation receipt in Wise branded PDF format
GET /transfers/{transferId}/us-combined-receipt.pdf load The US Combined Receipt in Wise branded PDF format
PUT /transfers/{transferId}/cancel update Returns the cancelled transfer object, with or without an originator block depending on the type of transfer
