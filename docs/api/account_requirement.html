create

POST /quotes/{quoteId}/account-requirements

Operation ID: recipientAccountRequirementsPost.

Authentication: bearer token (UserToken).

Parameters

Parameter In Type Required Description
quoteId path string Yes Quote ID (supports long or UUID-based IDs).
originatorLegalEntityType query enum: BUSINESS, PRIVATE No Legal entity type override for the actual sender. Correspondent partners must include the originatorLegalEntityType query parameter to ensure the correct requirements are returned in the response. This parameter indicates whether the actual sender is PRIVATE or BUSINESS. When not included, the request is assumed to be for a BUSINESS entity, as Wise has no way of knowing if the true sender on a third-party transfer is a business or private individual.
Accept-Minor-Version header enum: 1 No Set to 1 to ensure the response includes both the recipient name and email fields, which are required to support currencies such as KRW, JPY and RUB.
X-External-Correlation-Id header string (uuid) No Optional UUID for correlating requests across systems. If provided, Wise echoes it back in the response. Maximum 36 characters. Learn more.
