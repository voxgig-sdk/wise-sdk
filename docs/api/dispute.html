API

Dispute

A card transaction dispute: submit, list, get or withdraw one, or upload a file for it.

Operations

Every route this entity exposes. Each route links to its own reference on this page.

Method Route SDK operation Returns
POST /spend/profiles/{profileId}/dispute-form/flows/{scheme}/{reason} create Dynamic Flow JSON response. If using the Dynamic Flow framework, pass this to the framework. If using the API directly, the response can be ignored.
POST /spend/profiles/{profileId}/dispute-form/file create A key-value pair mapping the file name to the assigned file ID
GET /spend/profiles/{profileId}/disputes list Paginated list of disputes
GET /spend/profiles/{profileId}/disputes/{disputeId} load The dispute
PUT /spend/profiles/{profileId}/disputes/{disputeId}/status update The updated dispute

Operation ID: disputeSubmit.

Authentication: bearer token (UserToken).

Parameters

Parameter In Type Required Description

scheme path enum: MASTERCARD, VISA Yes The network of the card that was used to make this transaction.
reason path string Yes Dispute reason code supplied by the dispute reasons endpoint.
X-External-Correlation-Id header string (uuid) No Optional UUID for correlating requests across systems. If provided, Wise echoes it back in the response. Maximum 36 characters. Learn more.

Request body

application/json

Property Type Required Description

files object No Key-value pairs mapping file field names to file IDs obtained from the file upload endpoint. Available file fields vary per reason code.

transaction object No Transaction details for the dispute.
transaction.email string No Email of the support team that Wise should reach out to.
transaction.transactionId string No ID of the transaction.
