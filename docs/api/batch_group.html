API

BatchGroup

A batch group of transfers: create, get or update one, add a transfer, or fund it from a balance.

Operations

Every route this entity exposes. Each route links to its own reference on this page.

Method Route SDK operation Returns
POST /profiles/{profileId}/batch-payments/{batchGroupId}/payments create Batch group funded successfully
POST /profiles/{profileId}/batch-groups/{batchGroupId}/transfers create Transfer created successfully. Returns a transfer object
POST /profiles/{profileId}/batch-groups create Batch group created successfully. Note that payInDetails is empty for newly created batch groups.
GET /profiles/{profileId}/batch-groups/{batchGroupId} load Batch group retrieved successfully
PATCH /profiles/{profileId}/batch-groups/{batchGroupId} update Batch group updated successfully
