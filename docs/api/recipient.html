API

Recipient

A recipient account: create, list, get or deactivate one.

Operations

Every route this entity exposes. Each route links to its own reference on this page.

Method Route SDK operation Returns
POST /accounts/{accountId}/quotes/{quoteId}/compatibility create Returns the compatibility result, including any verification outcomes. See the Recipient verification guide for details about handling the confirmations object
POST /accounts create Recipient account created successfully
GET /accounts list Paginated list of recipient accounts
GET /accounts/{accountId} load Recipient account details
DELETE /accounts/{accountId} remove Recipient returned with active=false
PATCH /accounts/{accountId}/confirmations update Recipient with updated confirmation status
