BankAccountDetailsOrder

An order for bank account details: create one, or list them.

Operations

Every route this entity exposes. Each route links to its own reference on this page.

Method Route SDK operation Returns
POST /profiles/{profileId}/account-details-orders create Bank account details order created. The objects in the requirements array include the type and status of each requirement. All requirements must be fulfilled to complete the order.
GET /profiles/{profileId}/account-details-orders list A list of bank account detail orders
