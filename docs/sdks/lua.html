Configuration

Set the server URL and credentials for your environment. Enable only the features your application needs.

  • Debug capture
  • Idempotency
  • Metrics
  • Paging
  • Rate limiting
  • Retry
  • Secrets
  • Test transport
  • Timeout

Set up the client

This setup fragment reads credentials from the environment. Use the API operation reference to supply input for each call.

local sdk = require("wise_sdk")
local client = sdk.new({apikey = os.getenv("WISE_APIKEY")})
